# TasteShift

TasteShift to aplikacja o jedzeniu, która pomaga planować posiłki, wspierać zdrowe nawyki i śledzić postępy.

## Co oferuje

- Liczenie kalorii i makroskładników.
- Pomoc w układaniu planu posiłków.
- Przepisy, które użytkownicy mogą udostępniać publicznie albo zachować jako prywatne.
- Propozycje zdrowszych zamienników produktów i dań.
- Podpowiedzi, co warto zjeść przed treningiem i po nim.
- Chat do rozmów i uzyskiwania pomocy związanej z jedzeniem.
- Śledzenie masy ciała i obserwowanie efektów.

## Dla kogo

Dla osób, które chcą lepiej planować jedzenie, poznawać przepisy lub wspierać swoje cele związane ze zdrowiem i aktywnością fizyczną.

## Jaki problem rozwiązuje

TasteShift łączy planowanie posiłków, informacje o wartościach odżywczych, przepisy i śledzenie postępów w jednym miejscu, ułatwiając codzienne decyzje dotyczące jedzenia.
